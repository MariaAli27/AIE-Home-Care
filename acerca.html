Acerca del sitio

Información sobre este proyecto web.

Objetivo

El sitio web AIE Home Care fue desarrollado con el objetivo de presentar los servicios de una empresa dedicada a la limpieza y mantenimiento residencial.

Tecnologías utilizadas

El proyecto utiliza HTML5, CSS3, Bootstrap, JavaScript, jQuery, archivos JSON, consumo de API REST y Google Maps.

Diseño responsivo

El sitio utiliza Bootstrap y estilos adaptables para permitir su visualización en teléfonos, tabletas y computadoras.
